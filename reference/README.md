# Reference Materials (`reference/`)

Place reference materials for the chip you are designing in this directory—for example:

- Architecture notes, block diagrams, and design memos
- Interface / protocol specifications and timing diagrams
- Reference papers, algorithms, and datasheets
- Test vectors or golden model notes

AI agents (Gemini / Antigravity) can read files placed here alongside `docs/design-spec.md` when designing RTL, constraints, and testbenches.
