# Google / SkyWater SKY130 PDK Setup Guide (`pdk/profiles/sky130.yaml`)

This profile integrates the official **Google / SkyWater 130 nm CMOS Open PDK (`SKY130`, `sky130_fd_sc_hd`)** via Git Submodule (Option B: decoupled adapter profile).

- **Upstream Repository**: https://github.com/google/skywater-pdk
- **Standard Cell Library**: `sky130_fd_sc_hd` (`unithd`, `0.46 × 2.72 µm`, `1.80 V`, `met1–met5`)
- **Flow Driver**: `openroad_std` (Yosys → OpenROAD Floorplan/Placement/Routing → KLayout GDS/DRC/LVS → OpenSTA)

---

## Quick Setup (Single Target PDK Policy)

### Option 1: Mount `google/skywater-pdk` as a Git Submodule

1. **Remove the default target PDK submodule (`pdk/tr1um`)** (only ONE target PDK is allowed per design repo):
   ```bash
   git submodule deinit -f pdk/tr1um
   git rm -f pdk/tr1um
   rm -rf .git/modules/pdk/tr1um
   ```

2. **Add `google/skywater-pdk` as a Git Submodule and initialize `sky130_fd_sc_hd`**:
   ```bash
   git submodule add -b main https://github.com/google/skywater-pdk.git pdk/sky130
   git -C pdk/sky130 submodule update --init libraries/sky130_fd_sc_hd/latest
   ```

3. **Generate Liberty timing files and build merged EDA views** (written to `output/pdk_cache/sky130/` so the submodule stays clean):
   ```bash
   make -C pdk/sky130 timing
   python3 scripts/prepare_sky130.py
   ```
   > **Note on KLayout DRC/LVS decks**: Raw `google/skywater-pdk` provides Foundry cell views (`.lib`, `.tlef`, `.lef`, `.gds`, `.spice`, `.v`) without pre-compiled KLayout DRC/LVS rule decks. To enable KLayout DRC/LVS, either pass an `open_pdks`/`volare` `sky130A` directory via `SKY130A_ROOT=/path/to/sky130A python3 scripts/prepare_sky130.py` or use Option 2 below. When DRC/LVS decks are not present, set `signoff.drc: false` / `signoff.lvs.enabled: false` in `design.yaml` for synthesis + P&R + STA runs.

### Option 2: Pre-Built `sky130A` (`volare` / `open_pdks`)

If you already have a `volare` or `open_pdks` compiled `sky130A` tree (which includes merged `sky130_fd_sc_hd` views **and** KLayout `sky130A_mr.drc` / `sky130.lvs`), mount or symlink it at `pdk/sky130` (or point `SKY130A_ROOT` to it) and run:
```bash
python3 scripts/prepare_sky130.py
```

---

## Activate in `design.yaml` & Run

```yaml
pdk:
  name: "sky130"
  profile: "pdk/profiles/sky130.yaml"

design:
  top_module: "top"
  top_cell: "sky130_<your_github_user>"

signoff:
  mdp:
    enabled: false
```

Then validate and execute the pipeline:
```bash
python3 scripts/validate.py --stage pre
bash flow/run_all.sh
```
